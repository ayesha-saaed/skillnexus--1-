# SkillNexus – AI-Powered Skill Development & Career Guidance Platform

## Overview

SkillNexus is an AI-powered web application developed as a Final Year Project (FYP) to help students, graduates, and professionals identify skill gaps, explore learning resources, analyze career opportunities, and stay updated with industry trends.

The platform combines Artificial Intelligence, skill analysis, learning recommendations, community engagement, and career insights to provide a complete skill development ecosystem.

---

### AI Skill Analysis
- Analyze user skills using AI
- Identify strengths and weaknesses
- Generate personalized recommendations
- Career-focused skill matching

### Learning Resource Library

- Easy access to learning materials

### Admin Panel

## Installation

### Prerequisites

- Node.js
- npm

### Clone Repository

```bash
git clone <repository-url>
cd skillnexus
Install Dependencies
npm install
Environment Variables

Create a .env file and configure:

GEMINI_API_KEY=your_api_key
SUPABASE_URL=your_supabase_url
SUPABASE_ANON_KEY=your_supabase_key

### Run Development Server
npm run dev
Build Production Version
npm run build
Preview Production Build
npm run preview
